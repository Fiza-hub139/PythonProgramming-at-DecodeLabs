### 📌 Task 2: Expense Tracker
A functional tool to record, track, and analyze personal expenses over time.

- **Key Features:**
  - Record daily income and expenses with categories (e.g., Food, Travel, Utilities)
  - View summary reports and totals by date or category
  - Persistent storage for financial logs
- **Tech Stack:** Python 3.x

## 💻 Getting Started

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/downloads/) installed on your machine.

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Run the application:**
   ```bash
   python task01.py or expencetracker.py
   ```
